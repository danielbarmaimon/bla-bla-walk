## Done

Isolated mountShadowOverlay(map, options) consumes existing ShadeResponse cells.
North-first LV95 cells become exact cell polygons; sunlit is transparent, unknown
and night use different dash patterns, and shade uses the existing theme colour.
SHADOW_STATES exports text labels so D can provide a non-colour-only legend.
No network calls or generated fallback shadows exist in the module. Every update
clears old cells, including missing/invalid input; metadata and counts are retained.

## Integration hooks

D mounts the exported module and alone decides layer stacking/map wiring. Options:
visible (default false), zIndex (default 2), onStatus(status), projectCoordinate.
For the existing EPSG:3857 view, projectCoordinate([LV95 east,north], targetCRS)
must use a verified CRS transform. Without it the overlay is explicitly unsupported
and empty; OpenLayers does not ship EPSG:2056 by default. A native EPSG:2056 view
needs no callback. There is no approximate/identity CRS fallback.

Call update(response) only with the current viewport/time /api/shade response.
Clear with update(null) immediately on new request, route/time change, failure or
cancel; D owns request cancellation/generation checks. setVisible(bool) toggles the
layer; dispose() removes it and clears data. Dispose is idempotent. Surface
status.explanation, status.model, status.shade requested/effective time and geometry
version alongside SHADOW_STATES. Keep temperature and route samples distinct.

Display is bounded to 65,536 cells (256m square at 1m); larger responses are
explicitly unavailable. This establishes neither arbitrary-route support nor
city-wide/physical accuracy. Building-only approximation limits remain in T23.
