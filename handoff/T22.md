## Integration hooks for D

`import { mountJourneySteps } from './journey-steps.js'`.
`const steps = mountJourneySteps(container)`; `steps.update(selectedMapFeature,
{ amenities: routeAmenities(...) })`; `steps.update(null)` clears stale results;
`steps.dispose()` clears the mount. Update on every route/pair change, including
saved routes; use the feature returned by the same walking-routes request as the
map, not an old route's directions. No additional provider request is needed.

Candidate prompts disclose unverified access, water and diversion; milestones
are preparation reminders, not medical advice or verified stops.

`routeAmenities` is exported by `src/route-amenities.js`; supply its array of
`{fraction, feature, distance}` candidates for the same selected geometry.
`journeyItems(route, amenities, landmarks)` exports the ordered items for isolated checking.
The renderer writes plain text, including street names, distance and estimated
segment minutes; it does not install styles or event listeners.

Optional `steps.update(route, {amenities, landmarks})` accepts existing sourced
place records `{label, coordinates, sourceUrl}`; default landmarks reuse the
three checked records in `src/wayfinding-places.js` without a demo-route special
case. Named real saved indoor-stop candidates in `amenities` can also become
references. Fixture/unsourced/generic “Mapped …” candidates cannot become turn
references. Pass `landmarks: []` to omit the default records. Matching is local
to each maneuver (25 m display-nearness limit using original mapped centres),
and every hint says mapped reference / visibility unverified. It never claims
a building centre is a visible entrance or the exact place to turn.

## Human-wayfinding correction

The original provider-step checkpoint worked technically but repeated “unnamed
path” was not useful enough for people. This is corrected, without assigning a
nearby street's name to an unnamed segment or deleting actual turns:

- Use the provider's street name or road reference when supplied; otherwise
  locate the turn after the preceding named street and before the next named
  street, with its actual distance along the route. Arrival remains pair-neutral.
- Example from the checked second pair: “Turn left. After Hammerstrasse; route
  continues to Wettsteinstrasse in 248 m.” This is route context, not a claim that
  the current turn is onto Wettsteinstrasse.
- The SBB alternate actually produces “Turn left on Barfüsserplatz” and later
  “Continue straight on Gerbergasse”, with a nearby sourced Barfüsserplatz hint.
- Short segments now show seconds: 6 m / 6 seconds no longer becomes one minute.
- The checked pairs have no saved named supermarket within 50 m of a maneuver.
  No “turn at Migros” is invented. The saved church/building centres are too far
  from these maneuvers for the 25 m reference criterion; no church turn is claimed.
  Full landmark guidance on arbitrary routes still needs expanded source-backed
  landmark evidence and visibility/entrance verification. Existing geometry and
  directions remain unverified for access, closures and physical usability.
