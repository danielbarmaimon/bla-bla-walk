## Integration hooks for D

`import { mountJourneySteps } from './journey-steps.js'`.
`const steps = mountJourneySteps(container)`; `steps.update(selectedMapFeature,
{ amenities: routeAmenities(...) })`; `steps.update(null)` clears stale results;
`steps.dispose()` clears the mount. Update on every route/pair change, including
saved routes; use the feature returned by the same walking-routes request as the
map, not an old route's directions. No additional provider request is needed.

Candidate prompts disclose unverified access, water and diversion; milestones
are preparation reminders, not medical advice or verified stops.

`routeAmenities` is exported by `src/route-amenities.js`; supply its array of
`{fraction, feature, distance}` candidates for the same selected geometry.
`journeyItems(route, amenities)` exports the ordered items for isolated checking.
The renderer writes plain text, including street names, distance and estimated
segment minutes; it does not install styles or event listeners.
