# T20 · Low-clutter, full-screen map flow

Status: in progress on `feat/map-ergonomics`.

## State

- The user selected phone and desktop/tablet as equal design priorities.
- On desktop in trip-planning mode, the map is now constrained to the viewport below the header while the left planner scrolls independently. Narrow layouts retain page scrolling.
- OpenLayers wheel zoom and drag panning no longer require the map to be focused first; keyboard map controls still use the map's focus.
- Implemented the map-mode viewport layout, collapsed “Map details” controls with an active-layer count and reset action, and large labelled zoom, center-trip and show-route controls.
- Route steps and map-feature provenance now share an expandable panel over the map. Selecting a map feature opens its details there. The panel scrolls internally; the map page stays fixed in map mode.
- Updated `docs/style-guide.md` to describe the current behavior.

## Done

- UI changes are in the working tree; no app tests or browser review have been run.
- Older/less digitally experienced user walkthrough remains outstanding.

## Next

- Visually review the flow at phone and desktop/tablet sizes, including keyboard and 200% zoom.
- Try the map flow with older and less digitally experienced users and record stumbling points without personal details.
- Continue the separate T6 work later: shade/time wiring, route evaluation, online/offline acceptance and other pending tasks remain incomplete.
